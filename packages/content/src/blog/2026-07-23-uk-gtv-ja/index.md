# Global Talent Visa（Exceptional Talent）とは
UKにおけるGlobal Talent Visa(GTV)は、科学、工学、医学、デジタルテクノロジー、芸術などの分野で優れた才能を持つ個人に対して発行されるビザです。このビザは、UKでの就労や研究活動を行うための特別な許可を提供し、優秀な人材を引き付けることを目的としています。
